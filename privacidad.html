Política de privacidad de la herramienta «Cerebro Maestro»

GBH Nutrición · uso interno · última actualización: 17 de septiembre de 2026

Esta página describe únicamente la herramienta interna «Cerebro Maestro», que GBH Nutrición utiliza para gestionar sus propios proyectos de Google Apps Script a través de las API de Google. No describe el servicio de nutrición ni la aplicación de pacientes de GBH Nutrición.

Quién la utiliza

Únicamente su titular, con la cuenta de Google de GBH Nutrición (gbh.nutricion@gmail.com). La herramienta no tiene otros usuarios ni está destinada al público.

A qué accede

Con el permiso que se concede en la pantalla de consentimiento de Google, la herramienta accede exclusivamente al código de los proyectos de Google Apps Script de esa misma cuenta (alcances script.projects y script.deployments). No accede al correo, a los contactos, a los ficheros de Drive ni a ningún dato de terceros, y no accede a datos de pacientes.

Para qué

Para leer y actualizar el código de esos proyectos y publicar sus implementaciones. Nada más.

Dónde se guardan los datos

El permiso de acceso (token) se guarda únicamente en el ordenador del titular. No se sube a ningún servidor, no se comparte con nadie y no se vende. La herramienta no conserva ninguna otra información obtenida a través de las API de Google.

Uso de los datos de las API de Google

El uso que esta herramienta hace de la información recibida a través de las API de Google se ajusta a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el permiso

En cualquier momento desde myaccount.google.com/permissions, o borrando el token del ordenador del titular.
